# 레벨 디자인 — 설명 없이 스스로 익히는 농장

## 1. 원칙
- **글로 가르치지 않는다.** 튜토리얼 문장 대신 손가락 아이콘 하나가 지금 할 일 하나만 가리킨다.
- **기능은 필요해지는 순간 나타난다.** 처음 화면에는 당근 한 칸과 농장뿐이다.
- **위험은 빛으로 보여 준다.** 황혼이 되면 사방 좀비 구멍이 위협도만큼 붉게 맥동한다.
- **보상은 크게, 자주, 랜덤하게.** 수확 대박, 치명타, 콤보, 황금 좀비, 축복 카드, 냥슬롯.

## 2. 드러나는 순서 (`Sim.check_reveals`)

| 조건 | 나타나는 것 |
|---|---|
| 시작 | 당근 슬롯, 농장 |
| 첫 수확 | 상점 (팔기) |
| 수확 6개 / 2일째 / 첫 황혼 | 방어작물 슬롯 |
| 수확 9개 / 2일째 | 고양이, 밤 맞이 버튼 |
| 2일째 | 냥슬롯, 배속 |
| 3일째 | 연구 |
| 첫 처치 | 도감 |

## 3. 손가락이 가리키는 것 (`Sim.guide`) — 위에서부터 하나만
1. 익은 작물 (초반 6개까지)
2. 아직 아무것도 안 심었다면 → 당근 슬롯 → 안쪽 빈 밭
3. 돈이 없고 창고가 찼다면 → 상점
4. 방어작물이 2개 미만이면 → 콩콩나무 슬롯 → 길목 칸
5. 검사냥을 살 수 있으면 → 고양이 버튼
6. 땅이 좁으면 → 지금 살 수 있는 가장 싼 땅

## 4. 7장 캠페인 (`assets/data/chapters.json`)

| 장 | 날 | 보스 밤 | 새로 배우는 것 |
|---|---|---|---|
| 1 첫 수확 | 1–5 | 5 그리즈 | 심기·수확·판매, 콩콩나무, 검사냥 |
| 2 농장이 커진다 | 6–10 | 10 호박왕 | 링 B, 상인냥, 마늘벽, 방패 돼지(옆에서 쏘기) |
| 3 방어선 | 11–15 | 15 닭사장 | 비행 까마귀 → 대공(궁수냥·선인장), 방면 배치 |
| 4 밭이냐 포탑이냐 | 16–20 | 20 | 땅굴 두더지 → 안쪽 방어, ★승급 |
| 5 고급 농업 | 21–30 | 25 좀비냥 / 30 | 고양이 사냥꾼, 주술사 우선 처치 |
| 6 긴 밤 | 31–45 | 40 그믐의 왕 / 45 | 벽 통과 유령, 발사 봉인 오라 |
| 7 무지개 농장 | 46–60 | 60 그믐의 왕(사방) | 최종전 → 엔딩 → 끝없는 밤·환생 |

- 각 장의 **마지막 보스 밤은 이길 때까지 같은 밤이 반복**된다 (장의 관문).
- 방치(오프라인) 진행은 보스 밤 앞에서 멈춘다 — 관문은 직접 지킨다.
- 1~6일은 좀비 체력을 줄이고 냥이집을 두 배로 튼튼하게 하는 "배우는 밤".
- 모든 밤의 웨이브는 고정 시드로 작곡되어 있다 (`nights.json`) — 같은 밤은 누구에게나 같다.

## 5. 도파민 장치

| 장치 | 확률/규칙 |
|---|---|
| 수확 대박 ×3 / 초대박 ×10 | 7% / 1.2% (+축복) — 금가루, 큰 글씨, 화면 번쩍, 잠깐 멈춤 |
| 치명타 | 5% 기본, 2배 피해 (+축복으로 확률·배율·번개 연쇄) |
| 콤보 | 2.5초 안에 연속 처치, 처치 코인 최대 +200% |
| 황금 좀비 | 3일째부터 밤마다 22% — 처치 시 큰 코인 + 씨앗 |
| 축복 카드 | 생존한 새벽마다 3장 중 1장, 보스 밤 뒤엔 희귀 이상, 씨앗으로 다시 뽑기 |
| 냥슬롯 | 판돈 10%/25%/50%/올인, 기대값 약 96%, 무지개 3개 ×150 |
| 입양 상자 | 씨앗 12개, 등급 일반 60 / 희귀 27 / 영웅 11 / 전설 2 |
