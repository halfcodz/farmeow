# 🐱✨ Meowmory — 보리와 잊힘의 숲 (데모)

기억을 잃은 고양이 **보리**가 빛의 정령 **루미**와 함께 흩어진 기억 조각을 찾아 떠나는
**2D 도트 액션 플랫포머** (Godot 4.3, PC / Steam 목표). 『오리와 도깨비불』 같은 분위기의 밤숲 탐험과 전투를 목표로 한 데모입니다.

> 이 저장소는 원래 농사·디펜스 게임 *Farmeow*였고, 같은 그래픽 자산으로 새 게임을 만들며 전부 갈아엎었습니다. 이전 버전은 git 기록에 남아 있습니다.

## 이야기
모리스 마테를링크의 『파랑새』(1908, 퍼블릭 도메인)를 느슨하게 각색했습니다.
- 빛의 요정 → 빛의 정령 **루미**, 요정 베릴륀 → 늙은 고양이 **베릴**
- '추억의 나라'(기억해 주는 동안 살아 있는 이들) → **추억의 가지**에서 만나는 엄마 고양이
- 아픈 아이를 위해 파랑새를 쫓다 숲에 삼켜진 고양이 — 데모는 세 번째 기억과 함께 끝납니다

## 데모 구성 (약 15~25분)
| 구역 | 배우는 것 |
|---|---|
| 깨어난 공터 | 이동 · 점프 · 루미 합류 |
| 첫 오솔길 | 할퀴기 3연격 · 첫 사당(저장) |
| 늙은 나무 | 베릴과의 대화 · 첫 번째 기억 |
| 메아리 협곡 | 벽 점프로 오르기 |
| 우듬지 · 추억의 가지 | 파랑 깃털(이중 점프) · 엄마 고양이 · 두 번째 기억 |
| 가시덤불 내리막 | 바람 발톱(대시) · 두 번째 사당 |
| 망각의 둥지 | 보스 **망각의 곰** (돌진 · 도약 충격파 · 낙석, 2페이즈) · 세 번째 기억 |

## 조작 (키보드 / 게임패드)
| 동작 | 키보드 | 패드 |
|---|---|---|
| 이동 | A D / ← → | 왼쪽 스틱 · 십자키 |
| 점프 (길게 = 높이) | Space · Z · K | A |
| 할퀴기 (위/아래 + 할퀴기) | X · J · 마우스 왼쪽 | X |
| 바람 발톱 (대시) | C · Shift · L · 마우스 오른쪽 | RB · B |
| 대화 | E · Enter | Y |
| 일시정지 | Esc | Start |

## 손맛 장치
코요테 타임 · 점프 버퍼 · 가변 점프 · 벽 오르기 발차기 · 히트스톱 · 화면 흔들림 · 적 하얀 번쩍임/찌그러짐 ·
베기 궤적 · 가산 빛 파티클 · 아래 찍기 반동 · 빛 조각 자석 · 2D 조명(루미 · 사당 · 버섯 · 기억 조각)

## 실행
Godot 4.3에서 `project.godot`를 열고 F5. 내보내기 프리셋(Windows / macOS / Linux)이 들어 있습니다.

### 자동 검증 (헤드리스)
```bash
godot --headless --path . res://tests/climb.tscn   # 벽 점프 등반 · 이중 점프 틈 · 대시 가시밭
godot --headless --path . res://tests/boss.tscn    # 보스 → 기억 3 → 데모 끝 흐름
xvfb-run godot --path . res://tests/shots.tscn     # 장면별 스크린샷 /tmp/mm_shots
```

## 구조
```
scripts/actors/   보리(player) · 루미 · 적 · 보스 · 소품
scripts/level/    맵 데이터(생성됨) · 월드 · 원경
scripts/ui/       HUD · 대화 · 회상 · 일시정지
scripts/story.gd  모든 대사와 기억
tools/            맵 생성기 · 땅 타일 생성기 · 효과음 합성기
```
맵을 고칠 때는 `tools/make_level.py`를 고친 뒤 `python3 tools/make_level.py scripts/level/level_data.gd`.
